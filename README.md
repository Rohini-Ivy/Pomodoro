# 🍅 Pomodoro Timer Application

An interactive, accessible, and customizable web-based Pomodoro Timer built with HTML5, CSS3, and modern Vanilla JavaScript (ES6+).

## 🌟 Features

- ⏱️ **Timer Controls:** Start, Pause, Resume, and Reset functionality.
- ⚙️ **Customizable Intervals:** Configurable session durations for Work (default 25 min), Short Break (5 min), and Long Break (15 min).
- 📊 **Session Tracker:** Tracks completed Work sessions and automatically cycles between Work and Break intervals.
- 🔔 **Audio Notifications:** Web Audio API sound alert when a timer reaches zero.
- 🎨 **Adaptive Color Themes:** Visual color transitions representing current mode (Work, Short Break, Long Break).
- ⌨️ **Keyboard Shortcuts:**
  - `Space`: Start / Pause timer
  - `R`: Reset current timer
  - `S`: Skip session
- ♿ **Accessibility & Responsive:** Built with ARIA live regions, semantic tags, full keyboard navigation, and responsive CSS.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, ARIA attributes for screen readers.
- **CSS3:** Custom CSS Variables, Flexbox, SVG Circular Progress Ring, CSS Animations.
- **JavaScript (ES6+):** Object-oriented state management, Web Audio API synthesis, local storage, keyboard listeners.
